# jdbrewer/tap

Homebrew tap for [Keycadence](https://github.com/jdbrewer/keycadence) and
[peekabot](https://github.com/jdbrewer/peekabot).

```bash
brew install --cask jdbrewer/tap/keycadence
brew install jdbrewer/tap/peekabot
```

`Formula/peekabot.rb` is generated by peekabot's release workflow, so change it through
`scripts/formula.sh` in that repo rather than here.
